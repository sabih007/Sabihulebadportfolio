# Project screenshots

Drop real captures of the live sites here, then reference them from
`data/projects.ts`:

```ts
coverImage: "/images/projects/buysellox.webp",
gallery: ["/images/projects/buysellox-detail-1.webp"],
```

Suggested: ~1600×1000 for covers, WebP or AVIF. `<ProjectCover>` renders a
designed typographic frame until a real file is referenced — it never fabricates
a mockup of a site that has not been captured.
